# Experiment 1.2.2 - Optimized Redux with Memoized Selectors

A React-based social media post composer with performance optimizations using memoized selectors, derived state, and React.memo.

## Features
- ✅ Memoized Selectors (createSelector)
- ✅ Derived State
- ✅ React.memo Components
- ✅ useMemo and useCallback
- ✅ Post Statistics
- ✅ Recent Posts View
